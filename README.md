Apptentive, now Alchemer Mobile / Alchemer Digital, is a mobile customer engagement and in-app feedback platform used to run surveys, message prompts (Notes), ratings/review prompts, and Fan Signals inside iOS, Android, React Native, and web apps. Its public Data API at data.apptentive.com gives customers read-only export and analytics access to app metrics (active users, retention, Love Percent, Net Fan Score, ratings, reviews), survey and note reporting, and raw people, device, conversation, and message records, plus a GDPR/CCPA data-request endpoint. Authentication is an X-API-KEY header issued and scoped from the Alchemer Digital dashboard; the service is SOC 2 Type 2 and ISO 27001 certified.

**Areas:** Company · Enterprise · Mobile · Customer Feedback · Surveys · Analytics · Customer Engagement · Voice of Customer

## How this profile is made

API Evangelist profiles a company's public API surface the way a developer would find it: the website, developer portal and documentation, the specifications it publishes, its public repositories, and its pricing, status and changelog pages. From that it derives the properties above — contracts split per API, workflows, schemas, collections, governance rules, plans and rate limits — and scores them against the published [Kin Score rubric](https://github.com/api-evangelist/kin-score).

The artifacts are published on [APIs.io](https://apis.io), not in this repository. This repository is the public record for Apptentive: the place to say something is wrong, missing or out of date, and to ask for a re-score or a removal.
