# Apptentive (Alchemer Digital) Data API

> Apptentive, now Alchemer Mobile / Alchemer Digital, is a mobile customer engagement and in-app feedback platform. The public Data API (`https://data.apptentive.com`) provides read-only export and analytics access to app metrics, ratings, reviews, surveys, notes, Fan Signals, and raw people/device/conversation/message data, plus a GDPR/CCPA request endpoint. Authentication is via an `X-API-KEY` header issued from the Alchemer Digital dashboard. Rate limit: 100 requests per 5 minutes per IP.

## API
- [Apptentive Data API (Swagger 2.0)](https://raw.githubusercontent.com/api-evangelist/apptentive/refs/heads/main/openapi/apptentive-openapi-original.yml): metrics, raw, experimental, and info endpoints. Base host data.apptentive.com.
